# Task: Free-tier endpoints (/v1/models, /v1/models/:id, /v1/providers, /v1/compare, /v1/changes)

## Description
Implement the five Free-tier REST endpoints. All responses include trust metadata. Filtering, pagination, and the compare endpoint's 5-model cap are enforced here.

## Acceptance Criteria
- [ ] `GET /v1/models` — returns paginated list of models; supports query filters `?provider=`, `?modality=`, `?min_context=`; default page size 50; `?page=` and `?per_page=` supported
- [ ] `GET /v1/models/:id` — returns single model by ID; 404 if not found
- [ ] `GET /v1/providers` — returns list of all providers with model count
- [ ] `GET /v1/compare?models=id1,id2,...` — returns side-by-side pricing for up to 5 model IDs; 400 if >5 IDs supplied; 404 if any model ID not found
- [ ] `GET /v1/changes` — returns recent price changes; supports `?since=` (ISO 8601 timestamp) and `?provider=` filters; default returns last 24h
- [ ] Every response body includes trust metadata (`confirmed_at`, `source`, `confidence`, `age_hours`, `change_velocity`) per model
- [ ] Invalid filter values (e.g. `?min_context=abc`) return RFC 7807 400
- [ ] All responses served from Redis cache where applicable (TTLs from Task 003)
- [ ] DB queries use existing pgx pool from `internal/database`
- [ ] Handler functions registered on `app.Group("/v1")` with Unkey auth middleware applied
- [ ] Unit tests for handler logic (use Fiber's `app.Test()` — no HTTP mocking)

## Technical Details
- New files: `internal/api/handlers/models.go`, `internal/api/handlers/providers.go`, `internal/api/handlers/compare.go`, `internal/api/handlers/changes.go`
- Queries read from `models`, `price_history`, and `sources` tables
- Pagination: `X-Total-Count` header on list responses
- Response shape for `/v1/models` list item: `{id, provider, name, modality, context_window, price_input, price_output, meta: TrustMeta}`
