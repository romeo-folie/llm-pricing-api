# Task: Developer+ endpoints (/v1/models/:id/history, /v1/recommend, /v1/context)

## Description
Implement the three Developer+ gated endpoints: price history, model recommendation, and the agent-optimised context snapshot. Free-tier keys hitting these routes must receive a 403.

## Acceptance Criteria
- [ ] `GET /v1/models/:id/history` — returns full price history for a model from `price_history` table; supports `?from=` and `?to=` ISO 8601 date filters; ordered descending by `confirmed_at`; 404 if model not found; Developer+ only
- [ ] `GET /v1/recommend` — accepts `?task=` (string), `?context=` (integer token count), `?max_price_input=` (float, per 1M tokens); returns models ranked by price ascending that satisfy all constraints; Developer+ only
- [ ] `GET /v1/context` — returns a compact JSON pricing snapshot suitable for agent system prompts; response verified ≤ 2,100 tokens when measured with tiktoken (cl100k_base encoding); includes top 50 models by usage, each with `id`, `provider`, `price_input`, `price_output`, `confidence`, `confirmed_at`; Developer+ only; cached 10 minutes
- [ ] Free-tier key hitting any of these endpoints returns RFC 7807 403 with `{"tier_required": "developer"}` extension field
- [ ] Trust metadata included on all model responses
- [ ] `/v1/context` response size enforced — if computed response exceeds 2,100 tokens, trim model list until it fits (log a warning)
- [ ] Unit tests for handler logic and the token-counting trim logic

## Technical Details
- New files: `internal/api/handlers/history.go`, `internal/api/handlers/recommend.go`, `internal/api/handlers/context.go`
- `/v1/context` token counting: use `github.com/pkoukk/tiktoken-go` or equivalent pure-Go tiktoken; measure the JSON-serialised response bytes and estimate token count (approx 4 chars per token is acceptable if a pure-Go tiktoken is not available)
- `/v1/recommend` ranking: ORDER BY `price_input ASC` in SQL after filtering by modality/context constraints derived from `?task=` hint (simple keyword map: "summarisation" → text, "vision" → multimodal, etc.)
- RequireTier("developer") helper from Task 002 gates these routes
